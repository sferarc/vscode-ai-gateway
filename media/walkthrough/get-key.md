# Get an AI Gateway API key

Create a key in the AI Gateway section of your Vercel dashboard. It starts with `vck_`. The steps are in [AI Gateway authentication](https://vercel.com/docs/ai-gateway/authentication-and-byok).

If the Vercel CLI is logged in on this machine (`vercel login`), you can skip the key and sign in with Vercel OIDC in the next step instead.
