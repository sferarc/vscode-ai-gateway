# Sign in

**Manage Authentication** asks for a sign-in method:

- **API Key**: name the session, for example Personal or Work, then paste the key. The gateway checks it before it is saved.
- **Vercel OIDC**: pick a team and a project. Offered only when the Vercel CLI is logged in.

The key or token is kept in VS Code's secret storage. You can add more sessions later and switch between them from the same command.
