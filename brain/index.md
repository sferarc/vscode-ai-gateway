# Brain

Knowledge vault for the Vercel AI Gateway VS Code extension, readable as an Obsidian vault. One topic per file, wikilinks for cross-references. It records how the extension works and why it is shaped the way it is, with a source path, commit or pull request for every claim. Where something is not known, the note says so.

The README is the user documentation. These notes are for someone changing the code.

History before 2026-10-08 lives in the SferaDev/SferaDev monorepo, which this repository was split out of (`1cf4df1`). Pull requests from that era are cited as `SferaDev/SferaDev#N`; a bare `#N` would point at the wrong repository.
